Sobre aquesta web

Aquesta no és una web oficial de la Generalitat de Catalunya. És un projecte independent que fa servir dades públiques per facilitar l'anàlisi dels viatges a l'estranger dels alts càrrecs i del personal directiu de la Generalitat de Catalunya.

No té cap vinculació amb la Generalitat de Catalunya ni amb cap administració pública.

Metodologia

Les dades, tal com venen

Aquesta web no corregeix cap valor. Els imports, les dates i els textos són els que publica la Generalitat. Quan detectem un problema (un import incomplet, un duplicat, una data que sembla errònia), el registre porta una marca que ho explica, però les xifres es calculen amb el valor original.

Què no compta a les xifres

  • Viatges amb una durada anòmala. Excloem els viatges que duren més que el 99% de la resta{% if llindar %} (ara mateix, més de {{ llindar }} dies){% endif %}. Són {{ n_exclosos }} registres i gairebé sempre són errors de data: per exemple, un viatge d'un dia publicat amb una data de tornada dos mesos més tard.
  • Duplicats. Alguns viatges s'han publicat dues vegades, amb identificadors diferents. Comptem només el registre original.

Tots dos tipus de registre continuen visibles a l'explorador i a les dades descarregables.

Com llegir els imports

  • L'import és per registre, no per persona: alguns registres inclouen les despeses de tota la comitiva i d'altres només les de qui viatja.
  • Un import de 0 € no sempre vol dir que el viatge fos gratuït. De vegades les despeses s'imputen al registre d'una altra persona, les paga un tercer o encara s'estan tramitant; quan les observacions ho diuen, el registre ho indica.
  • Els viatges de l'any en curs es van publicant amb retard: les xifres de l'any actual no són definitives.

Destinacions

Les destinacions arriben en text lliure ("Brussels", "Brussel·les", "BRUSSEL·LES"…). Per poder comptar per país, les normalitzem amb un diccionari; el nom original es conserva sempre.

L'anàlisi de destinacions no inclou els trams a l'Estat espanyol. Quan un viatge visita diverses destinacions (països o ciutats), la seva despesa es reparteix a parts iguals entre les destinacions diferents. Així, la suma de totes les destinacions coincideix amb la despesa dels viatges, però l'import atribuït a cada destinació és aproximat: en un viatge a tres ciutats no sabem quant s'ha gastat a cadascuna. Al mapa, cada bombolla se situa al centre del país.

Departaments i àmbits

Els departaments canvien de nom a cada legislatura, així que els agrupem en àmbits estables (Acció Exterior, Cultura, Empresa…). El nom original es conserva sempre.

Persones

El nom d'una mateixa persona no sempre s'escriu igual ("Natàlia Mas i Guix" i "Natàlia Mas Guix", amb accent o sense…). Els unifiquem automàticament ignorant accents, majúscules i la «i» entre cognoms. Els pocs casos que això no resol (un segon cognom que falta, un nom abreujat) s'unifiquen a mà, només quan el càrrec ho confirma. El nom original de cada registre es conserva.

La despesa mitjana diària d'una persona és la seva despesa total dividida pel total de dies de viatge. Al rànquing només hi surten les persones amb tres viatges o més. Recorda que l'import és per registre: en els viatges del president i dels consellers sovint inclou la despesa de tota la comitiva.

Distribució de la despesa per partida

Cada viatge detalla quatre partides: dietes i manutenció, allotjament, transport i altres despeses. A les pàgines de departaments i de persones, el percentatge de cada partida es calcula sobre la suma de les quatre, de manera que sempre sumen el 100 %. Només compten els viatges que entren a les xifres. En una persona, només hi surt la despesa dels seus viatges; en un departament, la de tots els viatges de l'àmbit.

Sexe

El conjunt de dades no inclou el sexe de les persones. L'estimem a partir del gènere gramatical del càrrec (conseller o consellera, director o directora, secretari o secretària…), perquè en català els càrrecs es declinen. Els pocs casos on el càrrec és neutre («gerent», «cap») o contradictori es resolen a mà. És una classificació binària feta només per a una anàlisi agregada i pot tenir errors; no s'ha de fer servir per etiquetar cap persona concreta.

Una dada atípica no és una irregularitat

Un viatge car o llarg pot tenir una explicació perfectament raonable. Aquesta web vol facilitar l'accés a unes dades que ja són públiques, no assenyalar ningú.

Dades

D'on surten

Del conjunt Viatges a l'estranger dels alts càrrecs i personal directiu de la Generalitat de Catalunya, publicat al portal de Dades Obertes de Catalunya.

Com s'actualitzen

Cada dilluns se'n descarrega una còpia completa i es compara amb l'anterior per detectar registres nous, esborrats o modificats. Les còpies es conserven, de manera que es pot saber quan va aparèixer cada viatge al portal. Les dades d'aquesta web són del {{ updated }}.

Descàrregues

  • Viatges (CSV): tots els registres, amb els valors originals i les marques que hi afegeix aquesta web.
  • Destinacions normalitzades (CSV): una fila per cada destinació de cada viatge, amb la ciutat i el país normalitzats.

Autora

Aquesta web l'ha feta Blanca Domènech Pellejà. Va néixer com a continuació d'una pràctica de l'assignatura de Visualització de dades del Màster Universitari en Ciència de Dades de la UOC, en què es van analitzar per primera vegada aquestes dades amb una sèrie de gràfics.

Aprofitant les hores dedicades a aquell treball, el projecte ha anat creixent: ara les dades es descarreguen cada setmana, es fa un seguiment dels canvis que hi fa el portal i s'ha construït aquesta web per poder-les consultar amb més facilitat i millorar-ne el producte final. L'objectiu és divulgatiu: acostar a tothom unes dades que ja són públiques i explicar amb transparència com s'han tractat.
